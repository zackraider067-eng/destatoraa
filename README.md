# MikroTik Security Tester

واجهة عربية محلية لمراجعة أمان MikroTik وHotspot، تعمل من المتصفح ومهيأة كتطبيق ويب تقدمي (PWA).

## V1.0
- لوحة نتائج موحدة تجمع حالة المحاكاة ومراجعة الضوابط وتحليل سجلات الدخول.
- محاكاة حسابية محلية لمساحة احتمالات بيانات Hotspot دون إرسال أي محاولة للراوتر.
- قائمة مراجعة يدوية من 12 بندًا مع نسبة اكتمال وأولويات للمراجعة.
- تحليل محلي لسجلات RouterOS/Hotspot حسب المصدر والتوقيت، مع مؤشرات للتكرار والذروة.
- رسوم بيانية لأعلى الدقائق نشاطًا وأكثر المصادر تكرارًا.
- تصدير تقرير موحد TXT يجمع حالة الضوابط ونتائج المحاكاة والسجلات المتاحة.

## حدود الأمان والدقة
التطبيق لا يتصل بالراوتر ولا ينفذ محاولات تسجيل دخول أو تخمين كلمات مرور. المحاكاة رياضية افتراضية، ومعدل الحساب المحلي لا يمثل سرعة محاولات عبر الشبكة. قائمة المراجعة يدوية؛ نسبة اكتمالها لا تثبت صحة الإعدادات أو خلو الشبكة من الثغرات. تحليل السجلات يعمل محليًا على النص الذي يلصقه المستخدم، وتختلف الصيغ والتوقيتات حسب إصدار RouterOS والإعدادات. مؤشرات التكرار والذروة ليست إثباتًا قاطعًا على هجوم. راجع إعدادات الراوتر وسجلاته الأصلية قبل اتخاذ إجراء.
