# MikroTik Security Tester

واجهة عربية للموبايل مبنية باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA)، ويمكن تغليفها لاحقًا كتطبيق Android.

## V0.2
- محاكي حسابي محلي لحجم فضاء البحث حتى 9,999,999,999 اسم مستخدم × 100 كلمة مرور.
- حساب موضع هدف افتراضي والزمن التقديري للوصول إليه.
- حساب متوسط الحالة النظرية وأسوأ حالة (مسح فضاء البحث كاملًا).
- مقارنة تأثير التأخير بين المحاولات على الزمن النظري.
- قياس أداء JavaScript محليًا على الهاتف.
- تصدير تقرير المحاكاة كملف نصي.
- قائمة مراجعة لإعدادات أمان MikroTik.
- دعم العمل دون اتصال بعد أول زيارة ناجحة.

## حدود الأمان والدقة
المحاكي لا يرسل محاولات تسجيل دخول إلى الراوتر، ولا يجرب كلمات مرور على أي جهاز. كل الأرقام نتائج رياضية تعتمد على معدل افتراضي يدخله المستخدم. اختبار أداء JavaScript على الهاتف لا يساوي معدل محاولات شبكة أو تسجيل دخول حقيقي.

## النشر
فعّل GitHub Pages من Settings → Pages واجعل Source هو GitHub Actions. بعد نجاح Workflow سيظهر رابط التطبيق في صفحة Actions أو Pages.

## التقنية
HTML + CSS + JavaScript + PWA. لا يحتاج التطوير اليومي إلى كمبيوتر؛ يمكن تعديل الملفات من متصفح الهاتف أو تطبيق GitHub.
