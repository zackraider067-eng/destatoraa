# MikroTik Security Tester

واجهة عربية للموبايل مبنية باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA).

## V0.4
- نموذج حسابي محلي مطابق لنطاق الكروت الذي حدده المستخدم: اسم المستخدم من 1 إلى 9,999,999,999 وكلمة المرور من 01 إلى 100.
- إجمالي فضاء الاحتمالات النظري: 999,999,999,900 تركيبة.
- تقدير موضع افتراضي ومتوسط وأسوأ حالة ومقارنة التأخير.
- تصدير تقرير المحاكاة.
- قياس أداء JavaScript محليًا.
- قائمة مراجعة أمان MikroTik وHotspot من 12 بندًا.

## حدود الأمان والدقة
لا ينشئ التطبيق قوائم تخمين ولا يرسل محاولات دخول إلى الراوتر أو يختبر كروتًا حقيقية. تقديرات الزمن حسابية افتراضية وليست قياسًا لسرعة الشبكة أو زمن اختراق فعلي. الزمن الحقيقي يعتمد على قيود المحاولات، وسياسات الراوتر، وطريقة توليد الكروت، ومراقبة الدخول.
