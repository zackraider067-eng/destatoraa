# MikroTik Security Tester

واجهة عربية محلية لمراجعة أمان MikroTik وHotspot، تعمل من المتصفح ومهيأة كتطبيق ويب تقدمي (PWA).

## V0.9
- محاكاة حسابية محلية لمساحة احتمالات بيانات Hotspot.
- تحليل قابلية توقع نمط أسماء المستخدمين وكلمات المرور.
- قائمة مراجعة يدوية من 12 بندًا لتأمين MikroTik وHotspot.
- حساب نسبة الضوابط التي أكد المستخدم مراجعتها، مع إبراز أولويات البنود غير المؤكدة.
- تصدير تقرير تقييم ذاتي TXT.
- تحليل محلي لسجلات RouterOS/Hotspot، مع تجميع الفشل حسب المصدر والتوقيت.
- رسوم بيانية لأعلى الدقائق نشاطًا وأكثر المصادر تكرارًا.

## حدود الأمان والدقة
التطبيق لا يتصل بالراوتر ولا ينفذ محاولات تسجيل دخول أو تخمين كلمات مرور. قائمة المراجعة يدوية؛ النسبة تعبر عن اكتمال المراجعة فقط، ولا تثبت أن الإعدادات صحيحة أو أن الشبكة آمنة. تحليل السجلات يعمل محليًا على النص الذي يلصقه المستخدم، وصيغ السجلات والتوقيتات تختلف حسب إصدار RouterOS والإعدادات. مؤشرات التكرار والذروة ليست إثباتًا قاطعًا على هجوم. راجع إعدادات الراوتر فعليًا قبل اتخاذ قرارات تشغيلية.
