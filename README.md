# MikroTik Security Tester

واجهة عربية للموبايل باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA).

## V0.7
- نموذج حسابي محلي لنطاق الكروت: اسم المستخدم 1 إلى 9,999,999,999 وكلمة المرور 01 إلى 100.
- تحليل قابلية توقع نمط بيانات الكروت.
- قائمة مراجعة أمان MikroTik وHotspot من 12 بندًا.
- تحليل محلي لسجلات RouterOS/Hotspot الملصوقة داخل التطبيق.
- تجميع حالات فشل الدخول حسب عنوان المصدر.
- قراءة طوابع زمنية بصيغ شائعة مثل YYYY-MM-DD HH:MM:SS وmon/DD/YYYY HH:MM:SS.
- رصد مؤشرات التكرار: 5 حالات من المصدر نفسه خلال 60 ثانية، وذروة 10 حالات في الدقيقة.
- عرض أعلى الدقائق نشاطًا وتصدير تقرير TXT.

## حدود الأمان والدقة
لا يتصل التطبيق بالراوتر، ولا ينفذ تخمين كلمات مرور أو ينشئ قوائم تخمين. تحليل السجلات يعمل محليًا على النص الذي يلصقه المستخدم ولا يرفع البيانات. تختلف صيغ السجلات حسب إصدار RouterOS والإعدادات والمنطقة الزمنية، لذلك قد لا تُكتشف كل الحالات أو تُقرأ كل التواريخ. حدود 5/60 ثانية و10/دقيقة مؤشرات فرز أولية وليست إثباتًا لهجوم. يلزم مراجعة السياق مع سجلات DHCP/Hotspot/Firewall قبل اتخاذ إجراء.
