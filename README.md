# MikroTik Security Tester

واجهة عربية للموبايل مبنية باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA)، ويمكن تغليفها لاحقًا كتطبيق Android.

## V0.3
- محاكي حسابي محلي لحجم فضاء البحث حتى 9,999,999,999 اسم مستخدم × 100 كلمة مرور.
- حساب موضع هدف افتراضي والزمن التقديري للوصول إليه، ومتوسط الحالة النظرية وأسوأ حالة.
- مقارنة تأثير التأخير على الزمن النظري وتصدير تقرير المحاكاة.
- قياس أداء JavaScript محليًا على الهاتف.
- قائمة مراجعة موسعة لأمان MikroTik وHotspot وكروت الإنترنت، تشمل قابلية توقع بيانات الكروت، حدود الجلسات، مشاركة الكارت، صفحة الدخول، ومراجعة السجلات.
- يعمل كتطبيق PWA ويمكنه العمل دون اتصال بعد أول زيارة ناجحة.

## حدود الأمان والدقة
المحاكي لا يرسل محاولات تسجيل دخول إلى الراوتر، ولا ينشئ قوائم تخمين أو يجرب بيانات كروت حقيقية. كل الأرقام نتائج رياضية تعتمد على معدل افتراضي يدخله المستخدم. معدل الحسابات المحلية على الهاتف لا يساوي معدل محاولات تسجيل الدخول عبر الشبكة. لا يمكن تحديد زمن استنتاج كارت فعلي بدقة دون معرفة طريقة توليد أسماء المستخدمين وكلمات المرور، وحجم فضاء الاحتمالات، وسياسات تحديد المحاولات وتسجيل الدخول.

## النشر
فعّل GitHub Pages من Settings → Pages واجعل Source هو GitHub Actions. بعد نجاح Workflow سيظهر رابط التطبيق في صفحة Actions أو Pages.

## التقنية
HTML + CSS + JavaScript + PWA. يمكن تعديل الملفات من متصفح الهاتف أو تطبيق GitHub.
