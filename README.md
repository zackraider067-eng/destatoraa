# MikroTik Security Tester

واجهة عربية محلية لمراجعة أمان MikroTik وHotspot، تعمل من المتصفح ومهيأة كتطبيق ويب تقدمي (PWA).

## V1.1
- لوحة نتائج موحدة تجمع حالة المحاكاة ومراجعة الضوابط وتحليل سجلات الدخول.
- محاكاة حسابية محلية لمساحة احتمالات بيانات Hotspot دون إرسال أي محاولة للراوتر.
- قائمة مراجعة يدوية من 12 بندًا مع نسبة اكتمال وأولويات للمراجعة.
- تحليل محلي لسجلات RouterOS/Hotspot حسب عنوان IP المستخرج والتوقيت، مع مؤشرات للتكرار والذروة.
- التحقق من صلاحية مكونات التاريخ بدل قبول التواريخ غير الصحيحة التي يحولها JavaScript تلقائيًا إلى تواريخ أخرى.
- إعادة رسم المخططات عند تغيير حجم الشاشة.
- حساب متوسط موضع الهدف باستخدام المتوسط الحسابي الصحيح لمواضع فضاء البحث.
- تحسين تحديث التطبيق دون حذف مخازن Cache تخص تطبيقات أخرى على النطاق نفسه.
- تصدير تقرير موحد TXT يجمع حالة الضوابط ونتائج المحاكاة والسجلات المتاحة.

## حدود الأمان والدقة
التطبيق لا يتصل بالراوتر ولا ينفذ محاولات تسجيل دخول أو تخمين كلمات مرور. المحاكاة رياضية افتراضية، ومعدل الحساب المحلي لا يمثل سرعة محاولات عبر الشبكة. قائمة المراجعة يدوية؛ نسبة اكتمالها لا تثبت صحة الإعدادات أو خلو الشبكة من الثغرات. تحليل السجلات يعمل محليًا على النص الذي يلصقه المستخدم. استخراج أول عنوان IP من السطر لا يضمن أنه عنوان العميل أو مصدر المحاولة في كل تنسيقات RouterOS؛ راجع السجل الأصلي قبل نسبة النشاط إلى جهاز معين. تختلف صيغ السجلات والتوقيتات حسب إصدار RouterOS والإعدادات. مؤشرات التكرار والذروة ليست إثباتًا قاطعًا على هجوم.
