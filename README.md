# MikroTik Security Tester

إصدار أولي لتطبيق Android بواجهة عربية، يعمل كتطبيق ويب تقدمي (PWA).

## V0.1
- محاكي حسابي محلي لتقدير عدد المحاولات والزمن النظري.
- قياس أداء JavaScript محليًا على الهاتف.
- قائمة مراجعة لإعدادات أمان MikroTik.
- دعم العمل دون اتصال بعد أول زيارة ناجحة.

## حدود الأمان
المحاكي لا يرسل محاولات تسجيل دخول إلى الراوتر، ولا يجرب كلمات مرور على أي جهاز. الزمن المعروض تقديري وفق المعدل الذي يدخله المستخدم، وليس معدلًا فعليًا للشبكة.

## النشر
فعّل GitHub Pages من Settings → Pages واجعل Source هو GitHub Actions. بعد نجاح Workflow سيظهر رابط التطبيق في صفحة Actions أو Pages.

## التقنية
HTML + CSS + JavaScript + PWA. يمكن لاحقًا تغليف الواجهة كتطبيق Android APK دون إعادة كتابة الواجهة.
