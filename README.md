# MikroTik Security Tester

واجهة عربية للموبايل مبنية باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA).

## V0.5
- نموذج حسابي محلي لنطاق الكروت: اسم المستخدم من 1 إلى 9,999,999,999 وكلمة المرور من 01 إلى 100.
- إجمالي فضاء التركيبات النظري: 999,999,999,900 عند افتراض استقلال المجالين.
- تحليل قابلية توقّع نمط اسم المستخدم وكلمة المرور: متسلسل، ثابت، أو عشوائي.
- توضيح أن كلمة المرور ذات 100 احتمال فقط توفر نحو 6.64 بت من مساحة القيم.
- تقدير موضع افتراضي ومتوسط نظري ومقارنة التأخير.
- تصدير تقرير المحاكاة وقياس أداء JavaScript محليًا.
- قائمة مراجعة أمان MikroTik وHotspot من 12 بندًا.

## حدود الأمان والدقة
لا ينشئ التطبيق قوائم تخمين ولا يرسل محاولات دخول إلى الراوتر أو يختبر كروتًا حقيقية. تقديرات الزمن حسابية افتراضية وليست قياسًا لسرعة الشبكة أو زمن اختراق فعلي. إذا كان اسم المستخدم معروفًا أو متسلسلًا، فقد لا ينطبق افتراض أن فضاء التركيبات كاملًا مستقل وعشوائي. الزمن الفعلي يعتمد على طريقة إصدار الكروت، وقيود المحاولات، وسياسات الراوتر، ومراقبة الدخول.
