# MikroTik Security Tester

واجهة عربية تعمل محليًا من المتصفح، ومهيأة كتطبيق ويب تقدمي (PWA).

## V0.8
- محاكاة حسابية محلية لمساحة احتمالات بيانات Hotspot.
- تحليل قابلية توقع نمط أسماء المستخدمين وكلمات المرور.
- قائمة مراجعة من 12 بندًا لتأمين MikroTik وHotspot.
- تحليل محلي لسجلات RouterOS/Hotspot الملصوقة داخل التطبيق.
- تجميع حالات الفشل حسب عنوان المصدر وتحليل التوقيتات الشائعة.
- رصد مؤشرات تكرار المصدر والذروة الزمنية.
- رسم بياني لأعلى الدقائق نشاطًا ورسم لأكثر المصادر تكرارًا.
- تصدير تقرير نصي للسجلات.

## حدود الأمان والدقة
التطبيق لا يتصل بالراوتر ولا ينفذ محاولات تسجيل دخول أو تخمين كلمات مرور. تحليل السجلات والرسوم يعملان محليًا على النص الذي يقدمه المستخدم ولا يرفعانه إلى خادم. تختلف صيغ السجلات والتوقيتات حسب إصدار RouterOS والإعدادات والمنطقة الزمنية؛ النتائج مؤشرات فرز أولية وليست إثباتًا قاطعًا على هجوم. قائمة المراجعة يدوية ولا تفحص الراوتر تلقائيًا.
