# MikroTik Security Tester

واجهة عربية للموبايل باستخدام HTML وCSS وJavaScript كتطبيق ويب تقدمي (PWA).

## V0.6
- نموذج حسابي محلي لنطاق الكروت: اسم المستخدم 1 إلى 9,999,999,999 وكلمة المرور 01 إلى 100.
- تحليل قابلية توقع نمط بيانات الكروت.
- قائمة مراجعة أمان MikroTik وHotspot من 12 بندًا.
- تحليل محلي لسجلات RouterOS/Hotspot الملصوقة داخل التطبيق، مع تجميع أسطر فشل الدخول حسب عنوان المصدر.
- وضع علامة مراجعة أولية للمصادر التي تظهر لها 5 حالات فشل أو أكثر في النص المدخل.
- تصدير تقرير مراجعة السجلات TXT.

## حدود الأمان والدقة
لا يتصل التطبيق بالراوتر، ولا ينفذ تخمين كلمات مرور أو ينشئ قوائم تخمين. تحليل السجلات يعمل محليًا على النص الذي يلصقه المستخدم ولا يرفع البيانات. تختلف صيغ السجلات حسب إصدار RouterOS والإعدادات، لذلك قد لا تُكتشف كل حالات الفشل. عتبة 5 حالات علامة فرز أولية وليست إثباتًا لهجوم. تقديرات الزمن رياضية افتراضية وليست قياسًا لزمن اختراق فعلي.
